Replay the confirmed log in relay order on a delivery-order violation

A live push or own-ack could fold a later op into the baseline before
a catch-up fetch delivered the earlier one; applied flags deduped but
never ordered, so the earlier op then applied on top and the replicas
diverged ("Older" vs "Newer" for the same relay log).

  confirmed log — the existing rebase replays it in relay order inside
  the same atomic transaction, so every delivery order converges.

  push folded before adoption was wiped by the restore while staying
  flagged, losing its effect permanently.
