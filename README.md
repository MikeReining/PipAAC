# Pip AAC

Open, non-predatory **augmentative and alternative communication (AAC)** for
families, late-talkers, SPED classrooms, and therapists — **pippaac.org**
(working title).

New product workspace (repo: **PipAAC**). Durable product truth lands in
`docs/product/` and `docs/strategy/` after the founder brief — not in this README.

This repo carries the shared Ikiro dev harness (agents router, execution playbook,
code maintainer, test guard, commit handoff, CI). Live work index:
`docs/phases/README.md`.

## Quick start

```bash
npm ci
bash scripts/install-test-guard.sh   # once; open a new shell after
npm run check:fast
```

Read `AGENTS.md` before changing anything. Durable process lives under `docs/`.
